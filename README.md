# BillEvents

BillEvents is an event discovery and ticketing platform designed for concerts, festivals and different type of events in Ethiopia.

## Project Status

🚧 In Development

## Tech Stack

### Frontend
- React
- Vite
- JavaScript
- Tailwind CSS

### Backend
Coming soon.

## Features

- Event discovery
- Event details
- Ticket purchasing
- Ticket waves
- Organizer event management
- Digital tickets
- QR-based ticket validation
- BillPay payment integration
